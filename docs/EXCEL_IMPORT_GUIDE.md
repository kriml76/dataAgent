# Excel表导入功能使用指南

## 功能概述

本功能允许您通过Excel文件快速创建数据库表并导入数据,无需编写SQL语句。

## 使用步骤

### 1. 准备Excel文件

Excel文件需要包含两个Sheet:

#### Sheet 1: 表结构定义

| 字段名* | 数据类型* | 是否主键 | 是否非空 | 默认值 | 字段注释 |
|---------|----------|---------|---------|--------|---------|
| id      | INT      | 是      | 是      |        | 主键ID  |
| name    | VARCHAR(100) | 否   | 是      |        | 姓名    |
| age     | INT      | 否      | 否      | 0      | 年龄    |
| email   | VARCHAR(255) | 否  | 否      |        | 邮箱    |
| created_at | DATETIME | 否  | 是      | NOW()  | 创建时间 |

**必填字段:**
- 字段名*: 数据库字段名称,只能包含字母、数字和下划线,必须以字母或下划线开头
- 数据类型*: SQL数据类型,支持以下类型:
  - `INT` / `INTEGER`: 整数
  - `VARCHAR(n)`: 可变长度字符串,如 `VARCHAR(255)`
  - `CHAR(n)`: 固定长度字符串
  - `DECIMAL(p,s)` / `NUMERIC(p,s)`: 精确小数,如 `DECIMAL(10,2)`
  - `DOUBLE` / `FLOAT`: 浮点数
  - `DATE`: 日期
  - `DATETIME` / `TIMESTAMP`: 日期时间
  - `BOOLEAN` / `BOOL`: 布尔值(MySQL中自动转换为TINYINT(1))
  - `TEXT`: 长文本

**可选字段:**
- 是否主键: 填写"是"或"否",标记该字段是否为主键
- 是否非空: 填写"是"或"否",标记该字段是否允许NULL值
- 默认值: 字段的默认值,字符串类型需要用引号包裹
- 字段注释: 字段的业务说明

#### Sheet 2: 数据行

第二个Sheet的名称将作为表名使用(建议与文件名一致)。第一行是表头,后续行是数据:

| id | name | age | email | created_at |
|----|------|-----|-------|------------|
| 1  | 张三 | 25  | zhangsan@example.com | 2024-01-01 10:00:00 |
| 2  | 李四 | 30  | lisi@example.com | 2024-01-02 11:00:00 |
| 3  | 王五 | 28  | wangwu@example.com | 2024-01-03 12:00:00 |

### 2. 下载模板

在数据源管理页面,点击任意数据源的"导入表"按钮,在弹出的对话框中点击"下载模板"按钮获取示例文件。

### 3. 上传并导入

1. 在数据源管理页面找到目标数据源
2. 点击操作列的"导入表"按钮
3. 在弹出的对话框中:
   - 点击"下载模板"获取标准格式
   - 按照模板格式准备您的Excel文件
   - 点击"选择Excel文件"上传文件
   - 点击"开始导入"执行导入

### 4. 查看结果

导入完成后会显示:
- 成功提示: 表名和插入的行数
- 失败提示: 具体的错误信息

导入成功后,展开数据源可以看到新创建的表。

## 注意事项

### 文件命名
- Excel文件名会自动转换为合法的表名
- 不支持中文字符,会被替换为下划线
- 确保文件名以字母开头

### 数据类型
- 严格按照SQL标准类型填写
- VARCHAR必须指定长度,如 `VARCHAR(255)`
- DECIMAL必须指定精度和小数位数,如 `DECIMAL(10,2)`

### 数据格式
- 日期格式: `YYYY-MM-DD` 或 `YYYY-MM-DD HH:MM:SS`
- 布尔值: 填写"是"/"否"、"true"/"false"、"1"/"0"
- 数字: 直接填写数字,不要加引号
- 字符串: 直接填写,系统会自动处理引号

### 限制
- 单个Excel文件大小不超过10MB
- 单次导入数据行数建议不超过10万行
- 如果表已存在,导入会失败

### 支持的数据库
- MySQL 5.7+
- PostgreSQL 12+
- Oracle 12c+
- SQL Server 2016+
- 达梦数据库
- H2数据库

## 常见问题

### Q: 导入失败,提示"表已存在"
A: 该表已在数据库中存在,请先删除旧表或修改Excel文件名。

### Q: 数据类型不匹配
A: 检查Excel中的数据类型是否符合SQL标准,特别是VARCHAR和DECIMAL需要指定长度/精度。

### Q: 中文表名或字段名
A: 系统会自动将非法字符转换为下划线,建议直接使用英文命名。

### Q: 大量数据导入很慢
A: 系统采用批量插入(每1000条提交一次),对于超大数据量建议分批导入。

### Q: 如何更新已有表的数据?
A: 当前版本仅支持创建新表,如需更新数据请使用数据库管理工具直接操作。

## 技术实现

### 后端
- **Excel解析**: EasyExcel
- **DDL生成**: 根据不同数据库方言自动生成CREATE TABLE语句
- **数据插入**: PreparedStatement批量插入,支持事务回滚

### 前端
- **UI框架**: Ant Design 6
- **文件上传**: multipart/form-data
- **API调用**: Axios
