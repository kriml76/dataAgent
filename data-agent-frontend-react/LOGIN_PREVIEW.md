# 🚀 启动查看科技感登录页面

## 快速开始

### 1. 安装依赖（如果还未安装）
```bash
cd /Users/liubenjun/Desktop/DataAgent/data-agent-frontend-react
npm install
```

### 2. 启动开发服务器
```bash
npm run dev
```

### 3. 访问登录页面
打开浏览器访问：**http://localhost:8999**

由于路由配置已将根路径 `/` 指向登录页面，您将直接看到极具科技感的登录界面。

## 🔧 技术栈

- **React 19** + **TypeScript 6**
- **Vite 8** (极速构建)
- **Ant Design 6** (UI 组件)
- **Canvas API** (粒子动画)
- **CSS3** (高级动画效果)

## 📱 响应式支持

- ✅ 桌面端 (>768px): 完整效果
- ✅ 平板端 (480-768px): 自适应布局
- ✅ 移动端 (<480px): 简化版本

## 🎬 动画性能

所有动画均使用：
- `requestAnimationFrame` 确保流畅度
- CSS transforms 而非 position 变化
- 粒子数量根据屏幕尺寸动态调整
- 组件卸载时正确清理资源

## 💡 自定义提示

如需调整视觉效果，可修改：

1. **颜色主题**: `LoginPage.css` 中的颜色值
2. **粒子密度**: `LoginPage.tsx` 中的 `particleCount` 计算
3. **动画速度**: CSS 中的 `animation-duration` 值
4. **字体样式**: CSS 顶部的 Google Fonts 导入
